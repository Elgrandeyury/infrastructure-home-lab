# Lab Notes

This file is for concise public notes from real lab work.

Use this format when documenting a session:

## Date / Topic

**Goal**  
What I was trying to configure, test, or understand.

**Environment**  
Only non-sensitive details about the systems involved.

**What I changed**  
A short description of the configuration or test.

**What happened**  
The result, including any issue that appeared.

**What I learned**  
The technical takeaway from the session.

---

> Do not publish passwords, secrets, private IP details, access tokens, personal data, or configuration that would expose a real environment.
